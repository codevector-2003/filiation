iThe easiest way: open the app's AI assistants screen and press Connect. It finds the assistants on your computer and writes their settings for you, keeping a copy of the old file.

Set it up by hand

Run this once in a terminal:

claude mcp add filiation -- fil mcp

Start a new Claude Code session and ask it about your library.

Add this to claude_desktop_config.json. On Windows it is in %APPDATA%\Claude, on macOS in ~/Library/Application Support/Claude.

{ "mcpServers": { "filiation": { "command": "fil", "args": ["mcp"] } } }

Quit Claude Desktop completely and open it again.

Add this to ~/.cursor/mcp.json for every project, or .cursor/mcp.json for one:

{ "mcpServers": { "filiation": { "command": "fil", "args": ["mcp"] } } }

Add this to .vscode/mcp.json:

{ "servers": { "filiation": { "type": "stdio", "command": "fil", "args": ["mcp"] } } }

Copilot Chat can use it in agent mode.

Add this to ~/.gemini/settings.json:

{ "mcpServers": { "filiation": { "command": "fil", "args": ["mcp"] } } }

It loads the next time Gemini CLI starts.

What your assistant can do

search_libraryFind passages by keyword, with their page, to quote.
get_paperEverything about one paper, including why it has no PDF or text.
neighboursWhat a paper cites and what cites it, with the sentence it cites each in, when one was found.
find_pathThe chain of citations between two papers.
citation_groupsThe library's topics, found from its citations alone.
library_statsWhat is in the library.
add_paperAdd a paper by DOI, arXiv ID, PMID, OpenAlex ID, link or title.
expand_graphFollow references outward, within a budget.
fetch_pdfsDownload more open-access PDFs.
iAdd --read-only after mcp and the assistant can read your library but not add to it, and nothing it does reaches the network. Add --library Thesis to point it at another library.
