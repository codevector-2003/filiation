The app

Download the installer and run it. It installs for you only, needs no administrator rights, and adds fil to your PATH so a terminal and your AI assistant can find it.

Updating the app

On Windows the app keeps itself up to date. Once a day it asks GitHub for the latest version; when there is a newer one, Update to … appears in the title bar. Choose Update and restart: it downloads the installer, checks it against the release's checksums, and reopens on the new version with your library, settings and open tabs as they were. Help, Check for Updates… checks at once, and Check for Updates Automatically turns the daily check off. The check sends nothing about you or your library.

Versions 0.4.3 and earlier cannot update themselves: install the newest version over them once, from the download above. On macOS and Linux, download the new version from the latest release.

The command line

One file, nothing else to install. Download it from the latest release, unpack it, and run it.

Expand-Archive fil_{v}_windows_amd64.zip fil .\fil\fil.exe version
tar xzf fil_{v}_darwin_arm64.tar.gz sudo mv fil /usr/local/bin/ fil version

On an Intel Mac, download the darwin_amd64 archive instead.

tar xzf fil_{v}_linux_amd64.tar.gz sudo mv fil /usr/local/bin/ fil version

See where your library lives:

fil where
