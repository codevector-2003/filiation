The app

Download the installer and run it. It installs for you only, needs no administrator rights, and adds fil to your PATH so a terminal and your AI assistant can find it.

Download the Windows installer

!The installer isn't signed yet, so Windows SmartScreen may warn you. Choose More info, then Run anyway.

A macOS installer is coming. Until then, the app builds from source (see CONTRIBUTING.md), and the command line below works today.

A Linux package is coming. Until then, the app builds from source (see CONTRIBUTING.md), and the command line below works today.

The command line

One file, nothing else to install. Download it from the latest release, unpack it, and run it.

Expand-Archive fil_{v}_windows_amd64.zip fil .\fil\fil.exe version
tar xzf fil_{v}_darwin_arm64.tar.gz sudo mv fil /usr/local/bin/ fil version

On an Intel Mac, download the darwin_amd64 archive instead.

tar xzf fil_{v}_linux_amd64.tar.gz sudo mv fil /usr/local/bin/ fil version

See where your library lives:

fil where
